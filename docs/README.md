## 与代码的对应关系

- **几何**：文档里的坐标 == `utils/layout.js` 里的常量，改一处必须同步另一处；
- **视觉令牌**：亮度档 / 字号 == `utils/theme.js`；
- **状态名**：文档里的 `S.READY` / `S.PLAY` 等 == 页面代码里的状态常量；
- **验收项**：文档的验收表大多能在 `tests/navsim/` 找到对应断言（`B*` `G*` `P*` 分组）。

## 关于路径

文档的变更记录章节写于开发过程中，其中的 `.cache/` 指当时的本地工作缓存目录
（构建脚本、临时探针、截图）。开源整理时已把可复用的部分搬到
`tests/`（回归）与 `tools/`（工具），路径也已批量改写；若个别历史段落仍出现
`.cache/`，按"不外置、不入库的本地临时目录"理解即可。
